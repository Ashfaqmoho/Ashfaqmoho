## 🚀 Featured Projects

### 🛍️ ShopEase — Multi-Agent AI Customer Support

A multi-agent customer support application designed to organize customer requests into specialized workflows for order management, policy assistance, and refund handling.

- 🤖 Specialized agents for order, policy, and refund workflows.
- 🔀 Agent routing and workflow orchestration using LangGraph.
- 🛡️ Guardrails, authorization, and human approval mechanisms.
- 📦 Structured responses and workflow error handling.

**Tech Stack:** Python • LangGraph • LLMs • API Integration

### 📄 AI CV–JD Matcher — RAG-Powered Application

An AI-powered application that compares a candidate's CV with a job description, retrieves relevant information, and generates evidence-based matching scores and improvement suggestions.

- 📑 CV and job description document processing.
- 🔎 Embeddings, vector search, and retrieval-augmented generation.
- 🎯 Job-match scoring and skill-gap identification.
- 📌 Evidence-backed feedback and resume improvement suggestions.

**Tech Stack:** Python • Streamlit • LangChain • ChromaDB • Groq • PyPDF2

### 🚦 AI-Powered Road-Safety Detection

A computer vision project focused on identifying emergency vehicles and road-safety events from video footage.

- 🎥 Video-based object detection using custom-trained YOLOv8 models.
- 🚑 Emergency vehicle detection and visual highlighting.
- 👁️ Video processing using OpenCV.
- 🔔 Event detection and alert-oriented workflows.

**Tech Stack:** Python • YOLOv8 • Ultralytics • OpenCV
